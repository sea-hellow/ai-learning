## 二、镜像源配置

### conda（`.condarc` 已配好清华源）

```bash
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/r/
conda config --remove channels defaults
```

> 为什么移除 defaults：Anaconda 26.x 起，官方源强制要求先接受服务条款（`CondaToSNonInteractiveError`）。改用镜像可绕过，速度也快得多。

### pip

```bash
pip install --no-cache-dir <包名> -i https://mirrors.aliyun.com/pypi/simple/
```

**两个必须记住的点：**

1. **必须加 `--no-cache-dir`** —— 本机安全策略会拦截 pip 清理下载缓存的动作（判定为批量删除），导致 pip 中途被杀、所有包都装不上（报错里会出现 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`）。跳过缓存就没事。
2. **用阿里源，不要用清华 pip 源** —— 本机访问 `pypi.tuna.tsinghua.edu.cn` 会返回 403。

## 三、GitHub 访问（网络）

本机直连 github.com 不稳定，v2rayN 在 `D:\vpn\v2rayN-windows-64`，混合端口是 **10808**。

**关键：git 默认不使用 Windows 系统代理**，即使 v2rayN 开着系统代理也没用，必须单独配置：

```bash
git config --global "http.https://github.com.proxy" "http://127.0.0.1:10808"
git config --global http.version HTTP/1.1
```

已配置完成，只需保证推拉代码时 **v2rayN 处于运行状态**。

**为什么是 `http://` 而不是 `socks5://`**：git 自身（libcurl）两种协议都支持，但凭据管理器 GCM 是 .NET 实现，不认 `socks5://`，会报 `ServicePointManager 不支持具有 socks5 方案的代理`，然后退化成让你手输用户名密码（而 GitHub 早已不接受账户密码，只会失败）。

**验证是否通**（只读，不需要凭据）：

```bash
git ls-remote origin
```

能列出提交哈希就说明网络正常。

## 五、后续阶段会用到（提前记下）

- **阶段 4 装 PyTorch**：本机显卡是 RTX 5060（Blackwell 架构），必须用 cu128 源的版本，否则报 `no kernel image is available`：

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128 --no-cache-dir
```

- **Hugging Face 模型下载**：走国内镜像 `hf-mirror.com`（可在环境变量里设 `HF_ENDPOINT=https://hf-mirror.com`）。
- **模型与数据集缓存目录**：建议设在 D 盘，避免占满 C 盘。
- **matplotlib 中文显示**：默认会显示成方块，需要指定中文字体（如 `SimHei` 或 `Microsoft YaHei`）。
